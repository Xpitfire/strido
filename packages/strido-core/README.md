# strido-core

Robot-side Python library (numpy + pyserial only): generated geometry (`strido.geometry`),
linkage-exact leg kinematics (`strido.leg`), trot gait (`strido.gait`), MCU wire protocol
(`strido.protocol`), numpy policy runtime (`strido.policy`) and the bench tool `strido-cli`.
Used by the ROS 2 nodes, the MuJoCo simulation, the NT-X extension and the CAD tooling.
